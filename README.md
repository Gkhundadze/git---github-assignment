# დავალება — Git & GitHub

## მიზანი

დავალების მიზანია Git-ისა და GitHub-ის მუშაობის პრინციპების გააზრება, ვერსიების მართვის პროცესის შესწავლა და გუნდური მუშაობის დროს სწორი გადაწყვეტილებების მიღება.

დავალება მოიცავს როგორც თეორიულ საკითხებს, ასევე რეალურ სიტუაციებზე დაფუძნებულ კითხვებს.

**ინსტრუქცია:** ყურადღებით წაიკითხე თითოეული შეკითხვა და უპასუხე საკუთარი სიტყვებით. ეცადე, პასუხებში ახსნა არა მხოლოდ რა უნდა გააკეთო, არამედ რატომ არის კონკრეტული მოქმედება სწორი.

- Repository-ის ინიციალიზაცია.
